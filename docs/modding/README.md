## Building a modified ROM

- `make release` (or `make rom`) builds the ROM **without** the checksum tests.
- `make` also runs `check`, which compares against the retail SHA-1s. Any data
  change makes it fail; that is expected for a mod.
- SoulSilver: add `GAME_VERSION=SOULSILVER`.
- Output: `build/heartgold.us/pokeheartgold.us.nds`.

Keep an unmodified commit to diff against. Before changing data, confirm `make`
passes on that commit so you know any later mismatch comes from your edit.

## Status of each data type

| Data | Editable as text? |
|---|---|
| Base stats, types, abilities, TM/HM compatibility | yes (`personal.json`) |
| Evolutions | yes (`evo.json`) |
| Tutor moves | yes (`waza_oshie.json`) |
| Pokédex height/weight/text | yes (JSON) |
| Sprites, icons, footprints | yes (PNG) |
| Level-up moves | yes (`files/poketool/personal/level_up_learnsets.json`) |
| Egg moves | yes (`files/poketool/personal/egg_moves.json`) |
| Move data (power, type, accuracy, effect, flags) | yes (`files/poketool/waza/battle_moves.json`) |
| Move animations | **no**, binary `files/a/0/1/0` |
| Map headers | yes (`data/maps/<MapName>/map.json`) |
| NPCs, warps, signs, triggers | yes (`data/maps/<MapName>/map.json`) |
| Event scripts and text | yes (`scripts.pory`, `text.json` in the map folder) |
| Map grid (layout) | yes (`data/layouts/<Layout>/layout.json`) |
| Collision, tile behaviors, props | yes (`data/landdata/NNNN/permissions.txt`, `props.json`), or the map editor (`tools/mapeditor`) |
| Terrain 3D models | yes, through OBJ: `mapkit terrain export` / `import` ([terrain.md](terrain.md)); stored as `model.nsbmd` |
| Terrain heights | yes (`heights.json`, or generated from the model; [terrain.md](terrain.md)) |
| Area textures | **no**, binary NSBTX in `files/a/0/4/4` |
| Wild encounters | yes (`gs_enc_data.json` etc.) |
| Items (data, names, descriptions, icons) | yes (`data/items/items.json`, icon PNGs; [items.md](items.md)) |
| Mart stock | in C (`src/scrcmd_mart.c`; [items.md](items.md#marts)) |
| Trainers' parties | yes (`trainers.json`) |
| Trainer classes | in C and text (`trainer_class.h`, `msg_0730.json`, ...; [trainer-classes.md](trainer-classes.md)) |
| Trainer sprites and their animation | yes (PNG in `graphics/trainers/`, `data/trainer_graphics/*.json`; [trainer-classes.md](trainer-classes.md#trainer-sprites)) |
| Trainers' battle text tables | **no**, binary `trtbl.narc` |
| Music, sound effects, cries | index as text (`sound/sound_data.json`); new songs from MIDI, instruments from JSON + WAV; the game's own sequences, banks and samples stay binary but convert to MIDI / JSON / WAV ([music.md](music.md)) |
